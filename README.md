# leafpad_fltk_new
as requested by author - started it as new project
FLTK port of leafpad.
Even smaller,lighter and faster with even less features!

works:
- linewrap
- undo/redo 
- copy/paste/select all
- line numbers 

23kb binary with LTO 
35kb binary(LTO) with line numbers and search
11M RSS (TODO : reduce RSS memory use to make it run on old computers)
